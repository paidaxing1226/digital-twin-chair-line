# 数字孪生座椅产线

一个使用 Next.js、TypeScript 和 Three.js 构建的座椅生产线数字孪生 Web 看板。项目以大面积 3D 产线为主视图，实时展示框架组装、坐垫安装、扶手安装、质量检测、下线包装五个工位，并提供启停、故障注入、恢复和历史回放交互。

## 功能

- 3D 数字孪生场景：传送带、座椅装配动画、机械臂、工人、仓储货架、下线卡车和工厂围栏。
- 实时数据驾驶舱：OEE、产量、合格率、节拍、运行时长、故障次数和趋势图。
- 交互控制：启动、暂停、故障注入、恢复、重置、历史回放。
- 联动反馈：工位状态颜色与数据面板、3D 工位、底部状态条同步变化。
- 设备详情：点击 3D 工位或底部工位卡片后展示当前任务、节拍、良率和告警。

## 技术栈

- Next.js App Router
- TypeScript
- Tailwind CSS
- Three.js / react-three-fiber / drei
- SVG 数据图表
- Vitest
- lucide-react

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。

验证命令：

```bash
pnpm test
pnpm lint
pnpm build
```

如果你更偏好 npm，也可以使用 `npm install` 后运行同名脚本；本次开发环境中 npm 在依赖解析阶段多次超时，因此仓库提交 `pnpm-lock.yaml` 作为可复现锁文件。
