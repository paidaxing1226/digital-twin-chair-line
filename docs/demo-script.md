# 演示视频脚本

目标时长：3 到 5 分钟。

## 1. 开场与总览（约 30 秒）

1. 打开 `http://localhost:3000`。
2. 说明这是座椅产线数字孪生看板。
3. 展示第一屏的大面积 3D 产线：传送带、五个工位、机械臂、工人、仓储货架、卡车。
4. 用鼠标旋转和缩放视角，说明支持 3D 观察。

## 2. 启动生产（约 45 秒）

1. 点击“启动”。
2. 观察座椅沿传送带移动，机械臂开始摆动。
3. 指出顶部 KPI 中 OEE、产量、合格率、节拍随时间变化。
4. 展示底部五个工位状态颜色联动。

## 3. 设备点击与联动（约 45 秒）

1. 点击 3D 场景里的“坐垫安装”工位。
2. 展示右侧“选中设备”面板同步切换。
3. 再点击底部“质量检测”卡片，展示 3D 高亮和面板联动。
4. 说明详情包含当前任务、工位节拍、良率和告警。

## 4. 故障注入与恢复（约 75 秒）

1. 点击“注入故障”。
2. 观察选中或轮转工位变红，产线进入“故障处置”。
3. 展示右侧告警信息、OEE 下降、故障次数增加。
4. 点击“恢复”，观察工位回到运行状态，动画继续。

## 5. 暂停、重置与历史回放（约 45 秒）

1. 点击“暂停”，说明动画和生产推进停止。
2. 点击“启动”恢复运行。
3. 点击“回放”，展示最近历史快照循环回看。
4. 点击“重置”，展示指标和工位回到初始状态。

## 6. 结尾（约 20 秒）

1. 总结功能覆盖：3D 数字孪生、实时数据、交互控制、故障恢复、历史回放。
2. 展示 README 中的本地运行与验证命令。
