## 环境备注

本地 npm 安装过程中曾因代理环境变量和长时间依赖展开出现超时；最终使用 pnpm 完成依赖安装、锁定和验证。若继续尝试 npm，需要先清理代理变量：

```powershell
$env:HTTP_PROXY=''
$env:HTTPS_PROXY=''
$env:ALL_PROXY=''
npm install --registry=https://registry.npmjs.org/
```
